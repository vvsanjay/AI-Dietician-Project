# AI Dietician - BMR Meal Planner

This is a simple AI-based diet planning application built with Python and Tkinter. It calculates your BMR based on your gender, weight, height, age, and activity level. Then, using a heuristic approach, it suggests a set of meals to match your daily calorie requirement.

## Features
- BMR calculation using standard formulas.
- Meal planning using best-first search.
- Simple and interactive GUI using Tkinter.

## Run the App

```bash
python main.py
```

## Requirements

- Python 3.x
- Tkinter (comes pre-installed with Python)
